Каталог мережевого обладнання

Це навчальний каталог мережевого обладнання, призначений для ознайомлення з основними характеристиками маршрутизаторів, комутаторів та іншого мережевого обладнання.

Поля одного запису

  • name — назва або модель обладнання
  • manufacturer — виробник
  • type — тип обладнання
  • ports — кількість портів
  • speed — пропускна здатність
